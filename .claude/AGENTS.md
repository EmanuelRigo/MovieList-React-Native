# Project Agents Configuration

## Project Overview
React Native + Expo SDK 57 movie list application using:
- Expo Router for navigation
- NativeWind v4 for styling
- TanStack Query for remote data
- Zustand for global state
- Axios for HTTP client
- React Hook Form + Zod for forms

## Quick Reference
- Read [Expo SDK 57 docs](https://docs.expo.dev/versions/v57.0.0/) before writing code.
- Migrated from Next.js: see `PLAN_MIGRATION_RN.md`.
- Design system: see `DESING_SYSTEM.md`.
