# TanStack Query Skill

Esta skill define la integración de `@tanstack/react-query` para gestionar los datos asíncronos del backend Express.

## Reglas
1. Los custom hooks de query van en `src/queries/`.
2. Consumir los servicios definidos en `src/services/`.
3. Manejar revalidación e invalidación de query keys al mutar datos.
