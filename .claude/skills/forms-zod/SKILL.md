# Forms & Zod Skill

Esta skill estructura la validación de formularios en el cliente.

## Reglas
1. Usar siempre `react-hook-form` con `@hookform/resolvers/zod`.
2. Todos los esquemas de validación deben colocarse en `src/schemas/`.
3. Usar los componentes UI reutilizables (`AppInput`, `AppButton`).
